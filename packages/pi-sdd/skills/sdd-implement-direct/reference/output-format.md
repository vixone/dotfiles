# Evidence-based output

Discovery: spec ID, bound mission, explicit tier, revision, found/missing approved context, task IDs and dependency order. More than three tasks is a blocker requiring tier revision.

Candidate result: task ID, source revision, changed files, observed worker outcome, test commands/logs and blockers. Label worker success candidate, not complete.

Completion: verified tasks/total, actual combined commands and exit codes, pass/fail/skip counts, diff summary, drift and constitution findings, checkpoints and blockers. Missing logs/tests stays blocked. Offer local commit readiness only.
