# Phase output

Discovery: descriptor phase topology, current beads task receipts, verified phases skipped and interruptions requiring reconciliation. Markdown is static navigation, never execution state.

Task candidate: task ID, files changed, source revision, test evidence and blockers.

Phase review: completed/total tasks, combined test commands and exit codes, counts, drift and constitution findings, changed files and evidence paths. Ask Continue, Review output, Pause or Revise. Escape/cancellation pauses without a gate receipt.

Final/paused summary: task IDs, source/spec revision, verified phases/total, actual commands and pass/fail/skip counts, drift, blockers, remaining work. Resume reloads beads; no duplicate verified work.
